# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful and welcoming experience for everyone.

---

## Expected Behavior

- Be respectful.
- Be constructive.
- Help others learn.
- Welcome new contributors.
- Accept feedback professionally.

---

## Unacceptable Behavior

- Harassment
- Hate speech
- Personal attacks
- Offensive language
- Discrimination
- Spam

---

## Enforcement

Project maintainers may remove comments, commits, issues, or pull requests that violate this Code of Conduct.

Repeated violations may result in a permanent ban.

---

Thank you for helping build a positive open-source community.
